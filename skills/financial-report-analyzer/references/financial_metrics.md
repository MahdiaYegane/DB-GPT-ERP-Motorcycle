# Core Financial Metrics Reference

This reference defines the core metrics commonly used in financial report analysis and their formulas.

| Category | Metric | Formula | Meaning |
| :--- | :--- | :--- | :--- |
| **Profitability** | Gross margin | (Revenue - Cost of Revenue) / Revenue | Measures product competitiveness and profit potential |
| | Net margin | Net Profit / Revenue | Measures the company's ultimate profitability |
| | ROE (Return on Equity) | Net Profit / Average Equity | Measures return on shareholders' equity |
| **Solvency** | Debt-to-asset ratio | Total Liabilities / Total Assets | Measures financial leverage and risk level |
| | Current ratio | Current Assets / Current Liabilities | Measures short-term solvency |
| **Operating Efficiency** | Receivables turnover | Revenue / Average Receivables | Measures collection efficiency |
| | Inventory turnover | Cost of Revenue / Average Inventory | Measures inventory management efficiency |
| **Cash Flow** | Cash-to-profit ratio | Net Operating Cash Flow / Net Profit | Measures the cash quality of earnings |
